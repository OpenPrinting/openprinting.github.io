## Get help with printing

Ask about printer setup, printing problems, or CUPS in
**[OpenPrinting's Q&A forum](https://github.com/OpenPrinting/cups/discussions/categories/q-a)**.

Search for an existing answer first. To ask a question, sign in to GitHub and
start a discussion in **Q&A**. Include:

- Printer model and connection type (USB, Wi-Fi, or Ethernet).
- Operating system and version, plus your CUPS version if known.
- What went wrong, any error messages, and what you have already tried.

Remove personal information and passwords from logs or screenshots before posting.

## Reporting a bug

Report confirmed bugs in the affected project's tracker, such as
[CUPS issues](https://github.com/OpenPrinting/cups/issues).
For broken links or incorrect website content, use
[website issues](https://github.com/OpenPrinting/openprinting.github.io/issues).
